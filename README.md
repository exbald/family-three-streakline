# Streakline

Raised with [Family Three](https://github.com/exbald/family-three) on a Fly.io Sprite, not prompted.

It started as: “A tracker for my running. Weekly distance, a streak, nothing cute.”

Live: https://ft-family-b4zbc.sprites.app/a/streakline/ · https://exbald.github.io/family-three-streakline/

## Family line

Each commit in this repo is one ancestor. Its message is the brief its builder got. A cross is a merge commit.

- **C Dashboard**: Dense and dark. Everything important on one screen: big numbers, a chart drawn with SVG or canvas, a list. Monospace accents, a single bright accent colour.
- **C·1 Streakline** (from C): Keep the dense dark single-screen dashboard exactly as is, but make the streak the loudest element: a big lime flame-free number tile pinned to the top with the current count in the accent colour and a strip showing each logged day of the streak.
